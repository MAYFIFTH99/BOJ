# 입력과 출력

## Scanner

```java
Scanner sc = new Scanner(System.in);

int A = sc.nextInt();
int B = sc.nextInt();
```

> 만약 입력을 30 40 으로 하면 A = 30, B = 40 이 순수하게 들어가고 \n(엔터)는 버퍼에 남아있는 상태가 된다.


**C/C++/JAVA 에서 정수 / 정수는 '반드시' 정수가 나오므로, double로 강제 *형변환*을 해줘야 한다**
```java
Scanner scanner = new Scanner(System.in);

    int A = scanner.nextInt();
    int B = scanner.nextInt();

    System.out.println(**(double)** A / B);

```

혹은 그냥 선언부터 double 자료형을 쓰면 된다.

```java
    double A = Integer.parseInt(st.nextToken());
    double B = Integer.parseInt(st.nextToken());

    double result = A / B;
```
